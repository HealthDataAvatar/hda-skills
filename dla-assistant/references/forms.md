# DLA forms and output mapping

Last verified: **30 August 2026**.

## 1. Topic-first, not question-number-first

Do not organise the interview around hard-coded question numbers.

Forms are periodically reissued and E&W, Welsh and NI forms differ. A wrong version map is more dangerous than no question number.

Preferred order:

1. user attaches the actual form/pages; or
2. current official form is retrieved and version/date confirmed; then
3. map completed **topics** to the form's current boxes.

If form version is unconfirmed, use topic names only.

Never tell the user “put this in Q42” from memory.

## 2. Current official form hubs

England/Wales:
https://www.gov.uk/government/publications/disability-living-allowance-for-children-claim-form

Northern Ireland:
https://www.nidirect.gov.uk/publications/dla-child-claim-form-and-guidance-notes-dla1

Use current form notes as a claimant-facing procedural source, while statutory interpretation comes from law/decision-maker guidance.

## 3. Form page extraction

When the user attaches a form:
- identify jurisdiction;
- identify issue/version/date if visible;
- extract the exact wording of each relevant question;
- keep multipart prompts together;
- note any “tell us more” boxes;
- preserve limits/instructions;
- map topic drafts to the actual prompt only after the topic is factually complete.

If the form is a PDF/image and text is uncertain, inspect the page rather than guessing.

## 4. Answer drafting structure

A strong DLA free-text answer usually needs some combination of:

**What the child needs → what another person does → how often → how long → why → what happens without it → what is extra compared with same-age child → representative example → evidence reference.**

Do not turn every box into a legal essay. Answer the actual question asked.

## 5. New-claim topic map

Potential modules, activated only if relevant:
- conditions/treatments/history;
- aids/equipment;
- communication;
- personal care (washing/dressing/toileting/eating/etc.);
- medication/treatment/therapy;
- supervision/safety;
- development/cognition only insofar as it creates additional care;
- school/nursery support;
- night needs;
- walking/physical mobility;
- outdoor guidance/supervision;
- fluctuation;
- additional information/evidence.

Do not assume form headings correspond exactly across versions.

## 6. Mandatory Reconsideration output

E&W: follow current GOV.UK/decision notice route. Do not imply an optional form is always mandatory.

NI: current MR2(NI) exists; follow current decision notice/official DfC route.

MR content should be issue-led:

### Decision point 1: [finding]
**Why I disagree:** [factually precise reason]

**What [child] actually needs:** [help/supervision/guidance]

**How often/how long:** [quantified]

**Compared with a non-disabled child of the same age:** [additional element]

**Evidence:** [source/date and what it supports]

**Clarification from original form:** [if needed]

Repeat for each genuinely disputed point.

Avoid a generic “please reconsider because my child is disabled” letter.

## 7. Tribunal appeal grounds

Use the current tribunal route for jurisdiction.

Initial grounds should be concise enough to preserve/define the appeal, then can be developed with evidence as procedure allows.

Suggested structure:

> I appeal the decision dated [date] / Mandatory Reconsideration Notice dated [date] concerning [child]'s DLA.
>
> I disagree with the decision because [short summary of disputed care/mobility findings].
>
> **Issue 1 — [care/mobility test]**
> The department found [finding]. The factual position is [precise need], which occurred [frequency/duration] during the relevant period. The additional support compared with a non-disabled child of the same age was [difference]. This is supported by [evidence]. [Explain any original-form discrepancy if relevant.]
>
> **Issue 2 — ...**

Do not pretend to give a full legal submission if the case depends on contested case law; flag adviser review.

## 8. Tribunal written submission

If requested after the response bundle arrives, create:

1. decision under appeal;
2. agreed facts;
3. issues for tribunal;
4. applicable statutory tests;
5. evidence on each issue;
6. response to department's reasoning;
7. reconciliation of apparent inconsistencies;
8. concise conclusion asking tribunal to apply the relevant DLA tests to the established facts.

Use document/page references from the actual bundle where available.

## 9. Current-route discipline

Before giving a user:
- a phone number;
- email address;
- postal address;
- online appeal link;
- form code;
- deadline exception;

check the current official source when current-source access is available.

Never copy an old address from a prior claim form if the current decision letter says otherwise.
